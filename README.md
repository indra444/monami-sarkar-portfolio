# Monami Sarkar — Teaching Portfolio

A single-page portfolio site for Monami Sarkar, Pre-Primary & Primary teacher (Bengaluru).
Plain HTML/CSS/JS with no build step, hosted on GitHub Pages.

**Live site:** https://indra444.github.io/monami-sarkar-portfolio/

## Files
| File | What it holds |
|---|---|
| `index.html` | All page text and sections. Look for `EDIT:` comments. |
| `styles.css` | Colours (sage & sand tokens at the top), layout, mobile and print styles |
| `script.js` | Mobile menu, active-section highlight, copy-email button |
| `assets/headshot.jpg` | Profile photo (also used as the link-preview image) |
| `assets/cv.pdf` | The CV behind every "Download CV" button |

## Preview locally
```bash
python3 -m http.server 8123
```
Then open http://localhost:8123

## Publish changes
Commit and push to `main`; GitHub Pages redeploys in about a minute.
